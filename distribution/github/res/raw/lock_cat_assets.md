# Lock-screen mascot

The three 512 x 512 RGBA images in drawable-nodpi are the user-provided,
generated artwork from SLOOOP_CAT_ASSETS_ADDON_V1 (2026-10-16).
They share one authored canvas and must not be cropped independently.
No reference screenshots or unrelated artwork are bundled.

Head/parent pivot: (0.50, 0.72). Glasses pivot: (0.51, 0.35).
Glasses down: 8/96 of the measured PIN container, 10/140 of the biometric
container. Source alignment is already baked into the PNGs.
The static neutral PNG is an alternative, not a third visible layer.

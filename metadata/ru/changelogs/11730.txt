- Обновлён главный экран настроек в Material 3. Значки стали контурными, подписи расположены ближе к ним, убрана тень под верхней панелью.
- В редакторе автоскрытия можно выбрать режим для каждого правила — свернуть совпадение, скрыть его полностью или использовать общую настройку. Сохранённый режим виден в списке правил.
- Predictive Back автоматически включается при жестовой навигации Android. Настройка выхода из формы ответа одним жестом перенесена в «Интерфейс → Управление жестами».
- Через «Отправить файл → Slooop» фото или видео из галереи теперь прикрепляется к следующей открытой форме ответа, в которой есть место для вложения.
- В настройках видеоплеера появилась галочка «Игнорировать фокус аудио». Она позволяет воспроизводить видео в Slooop, пока в другом приложении играет музыка.
- Исправлено перекрытие нижних кнопок формы ответа клавиатурой. Фикс для Lenovo TB320FC включён по умолчанию.
- В классической боковой панели восстановлены пропорции счётчика избранных тредов.

- «Кекабу» больше не ограничивается режимом чтения: теперь после входа в Пикабу можно писать комментарии и ответы. Поддерживаются цитирование и базовое форматирование текста, а собственные комментарии можно удалять.
- Добавлена расширенная настройка скорости видеоплеера. В отдельном разделе можно выбрать обычный пресет либо задать точную скорость от 1% до 1000%. По умолчанию поведение плеера не изменилось.
- Добавлен экспериментальный режим чтения Reddit. Reddit можно включить в списке форумов, выбрать главную страницу или популярное сообщество, а затем читать официальный сайт внутри приложения с компактным оформлением Slooop.
- Reddit работает только для чтения публичных страниц: приложение не использует Reddit API, не выполняет автоматических действий и загружает дополнительные ответы только после действия пользователя.
- Исправлены предупреждения ресурсов и конфигурации сборки без изменения поведения приложения.

Добавлена авторизация прокси по логину и паролю. Для каждого форума можно отдельно настроить прокси или оставить прямое подключение.
В настройках прокси появилось предупреждение: антибот-проверка во встроенном браузере может пройти в обход прокси форума.
При отключении отслеживания ответов теперь можно оставить историю или удалить её из приложения.
После обновления через приложение появляется уведомление «Открыть Slooop» для быстрого возвращения.
Настройки скругления окон перенесены из специальных возможностей в раздел «Интерфейс».
Скорректированы некоторые иконки приложения, чтобы уменьшить лишний ободок в лаунчере.
Обновлена библиотека воспроизведения GIF. Удалена устаревшая libyuv: преобразование кадров программного видеодекодера теперь выполняется через FFmpeg.
Обновлена работа с системными API, очищен устаревший код и исправлены замечания статического анализа.

- Продолжаем обновлять интерфейс в стиле Material 3 😺 Доработаны диалоги настроек, сведения о тредах и файлах, параметры вложений и фильтры галереи. Приведены к общему стилю подписи, поля, переключатели и кнопки.
- Обновлён экран создания собственного ярлыка приложения: новое оформление элементов управления и предпросмотр изображения, подстраивающийся под ширину экрана.
- Добавлена экспериментальная настройка «Фикс для Max Relax» — для устройств, на которых клавиатура не появляется при открытии формы ответа. Находится в экспериментальных настройках, по умолчанию выключена.
- Исправлена ошибка установки обновлений: сохранённое состояние предыдущей установки больше не должно мешать открытию установщика для новой версии.
- Обновление отправлено в F-Droid и уже принято кураторами! В этой сборке вернулся офлайн-переводчик Mozilla Bergamot и появился новый редактор фото. Теперь ждём появления обновления в каталоге. 🐾

Вернуть старый дизайн можно здесь: Настройки → Экспериментальные функции → Новый интерфейс Material 3 → выключить «Включить новый интерфейс».
